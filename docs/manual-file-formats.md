# 文件格式支持手册

> 本文档详细说明 Niu 系统支持的文件格式，包括文件存储入库、知识图谱入库和照片入库的格式范围。
> 快速参考请见 [用户操作手册](manual-user-guide.md) 的"1.4 支持的文件格式"。

## 一、入库方式说明

Niu 有两种入库能力，格式支持范围不同：

| 入库方式 | 说明 | 格式范围 |
|----------|------|----------|
| 文件存储入库 | 将文件复制到知识库目录 `{workspace}/{year}/{category}/`（文档）或 `{workspace}/{year}/{month}/{date}/`（照片） | 所有文档格式 |
| 知识图谱入库 | 将文件内容写入 LightRAG 知识图谱，自动提取实体和关系 | 仅特定格式（见下文） |

> 拖入文件时，系统会自动判断格式：支持知识图谱的格式同时完成存储+图谱入库，不支持的格式仅完成存储。

## 二、文件存储入库支持的格式

所有以下格式均支持文件存储入库（复制到知识库目录）：

| 格式 | 扩展名 |
|------|--------|
| PDF | .pdf |
| Word | .docx, .doc |
| Excel | .xlsx, .xls |
| PowerPoint | .pptx, .ppt |
| 纯文本 | .txt |
| Markdown | .md |

### 2.1 文件命名规则

- **文档**：保留原文件名（如 `报告.pdf` 入库后仍为 `报告.pdf`）。
- **照片**：自动重命名为 `日期_时间.扩展名` 格式（如 `20260630_143022.jpg`）。

> 注：`preferences.json` 中的 `naming.documents` 字段（默认 `"{date}_{title}"`）当前未被代码使用，属于已废弃配置，文件名以原文件名为准。

## 三、知识图谱入库支持的格式

以下格式支持知识图谱入库（内容写入 LightRAG）：

| 格式 | 扩展名 |
|------|--------|
| PDF | .pdf |
| Word | .docx |
| Excel | .xlsx |
| PowerPoint | .pptx |
| 纯文本 | .txt |
| Markdown | .md |

## 四、不支持知识图谱入库的格式

以下格式支持文件存储，但**不支持知识图谱入库**：

| 扩展名 | 格式类型 | 不支持原因 |
|--------|----------|-----------|
| .doc | Word 旧版二进制格式（OLE2） | 二进制格式无法可靠提取纯文本，解析结果不完整或乱码 |
| .xls | Excel 旧版二进制格式（BIFF） | 二进制格式无法可靠提取纯文本，解析结果不完整或乱码 |
| .ppt | PowerPoint 旧版二进制格式 | 二进制格式无法可靠提取纯文本，解析结果不完整或乱码 |

### 4.1 WPS 假 .docx 检测机制

**问题**：WPS Office 创建的 .docx 文件，部分实际使用 OLE2 格式（即旧版 .doc 的二进制格式），而非标准的 OOXML 格式。这类文件虽然扩展名是 .docx，但内容是旧版格式，无法正确解析。

**检测机制**：程序在解析 .docx 文件时，会检测文件的实际格式：
1. 正常 .docx 文件：ZIP 压缩包（OOXML 格式），可以正确解析
2. WPS 假 .docx 文件：OLE2 格式，检测到后自动标记为不支持知识图谱入库

**处理方式**：
- 文件仍可正常存储入库
- 知识图谱入库步骤跳过，不会报错
- 系统会提示用户该文件为旧版格式

**解决方案**：用 Microsoft Office 或 WPS 打开文件，另存为标准 .docx 格式后重新入库。

## 五、照片入库支持的格式

| 格式 | 扩展名 | 存储 | 人脸识别 | 知识图谱 |
|------|--------|------|----------|----------|
| JPEG | .jpg, .jpeg | 支持 | 支持 | 不支持 |
| PNG | .png | 支持 | 支持 | 不支持 |
| GIF | .gif | 支持 | 支持 | 不支持 |
| BMP | .bmp | 支持 | 支持 | 不支持 |
| WebP | .webp | 支持 | 支持 | 不支持 |
| HEIC | .heic, .heif | 支持 | 支持 | 不支持 |

> 照片入库仅支持存储和人脸识别，不支持知识图谱入库。照片内容（文字等）不会被提取到知识图谱中。

## 七、常见问题

**Q: 为什么 .doc 文件不能入库知识图谱？**

A: .doc 是 Word 97-2003 的旧版二进制格式（OLE2），与 .docx 的 OOXML 格式完全不同。二进制格式无法可靠提取纯文本，解析结果可能不完整或乱码，因此不支持知识图谱入库。建议用 Office 另存为 .docx 格式后重新入库。

**Q: 为什么我的 .docx 文件也提示不支持知识图谱？**

A: 这可能是 WPS Office 创建的"假 .docx"文件。WPS 有时将旧版 .doc 格式的文件保存为 .docx 扩展名，实际内容仍是 OLE2 二进制格式。程序会自动检测并跳过知识图谱入库。解决方法：用 Microsoft Office 打开文件，另存为标准 .docx 格式。

**Q: .xls 和 .ppt 也不支持知识图谱吗？**

A: 是的。与 .doc 同理，.xls（BIFF 二进制格式）和 .ppt（旧版二进制格式）都无法可靠提取纯文本。建议另存为 .xlsx 和 .pptx 格式。

**Q: CSV/JSON/LOG/HTML 文件可以入库吗？**

A: 不可以。这些格式不在文档入库支持的扩展名集合中，拖入时会被标记为 `skipped`（"不支持的文件格式"）。如需将其中内容入库知识图谱，请先转换为支持的格式（如 .txt 或 .md）后再入库。

**Q: 照片可以入库知识图谱吗？**

A: 不可以。照片格式（.jpg/.png 等）仅支持存储和人脸识别，不会提取文字内容到知识图谱。如果需要将图片中的文字入库，请先将文字提取为 .txt 或 .md 文件再入库。
