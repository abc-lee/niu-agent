## 一、设计理念

### 1.1 核心理念

**灵魂态精灵 + 便利贴 = 有温度的个人助理**

- 悬浮精灵：动态的"鬼火"效果，像一个有灵性的小助手
- 便利贴：棉纸纹理 + 手写字体，温暖、自然、人性化
- 一切通过对话：用户只需要说话，助理处理一切

### 1.2 视觉风格

这套风格将作为整体页面的设计规范：

| 元素 | 风格 |
|------|------|
| 背景 | 棉纸纹理，米黄色系 |
| 文字 | 手写体（便签）/ 系统字体（正文）|
| 圆角 | 4-8px |
| 颜色 | 6色便签色系 |
| 动画 | 柔和、自然、有呼吸感 |

## 三、迷你态设计

### 3.1 视觉效果

```
         ∿∿∿
       ∿       ∿
      ∿   🌟   ∿    ← 类似鬼火的动态光晕
       ∿       ∿     有呼吸感的动画
         ∿∿∿
           ③       ← 待处理事务数量（红点或数字）
         
尺寸：60-80px
效果：半透明、发光、有微微飘动/呼吸动画
```

### 3.2 待处理事务提醒

**显示方式：**
- 右上角显示红点或数字
- 数字表示待处理事务数量
- 鼠标悬停可预览简要信息

**待处理事务类型：**

| 类型 | 说明 |
|------|------|
| 未命名人物 | 人脸识别后需要用户命名 |
| 文档分类待确认 | 文档自动分类需要确认 |
| 重复人物合并 | 检测到可能是同一人 |

### 3.3 参数规范

| 属性 | 值 |
|------|-----|
| 形状 | 圆形光晕，边缘模糊渐变 |
| 颜色 | 淡蓝色/淡紫色渐变，带微微发光 |
| 动画 | 呼吸感缩放 + 轻微飘动 |
| 透明度 | 0.6-0.8（呼吸变化） |
| 滤镜 | `blur(2px)` + `drop-shadow` |
| 位置 | 记住上次位置，默认屏幕右下角 |

### 3.3 动画代码

```css

    transform: scale(1);
    opacity: 0.7;
  }

    transform: scale(1.1);
```

### 7.4 字体自动缩放

**原则：便签内不出现滚动条，文字自动适配。**

```javascript
function adjustFontSize(container, text) {
  const maxFontSize = 18;
  const minFontSize = 10;
  let fontSize = maxFontSize;
  
  while (getTextWidth(text, fontSize) > containerWidth && fontSize > minFontSize) {
    fontSize -= 1;
  }
  
  return fontSize;
}
```

## 十一、动画规范

### 11.1 时间参数

| 动画 | 时长 | 缓动函数 |
|------|------|----------|
| 精灵呼吸 | 3s | `ease-in-out` |

### 11.2 过渡动画

```
精灵态 → 展开态：
  1. 精灵放大并淡出（0.2s）
  2. 展开窗口从精灵位置展开（0.3s）
  3. 各区域依次淡入（0.2s 间隔）

展开态 → 精灵态：
  1. 窗口收缩到精灵位置（0.3s）
  2. 精灵淡入并缩小到迷你态（0.2s）
```

## 十二、边缘吸附

### 12.1 效果

- 拖动精灵到屏幕边缘时自动吸附
- 吸附后只露出 20px 左右
- 鼠标靠近时自动滑出

### 12.2 实现

```javascript
// 检测边缘吸附
function checkEdgeSnap(x, y, screenWidth) {
  const threshold = 30;
  if (x < threshold || x > screenWidth - threshold) {
    return true;
  }
  return false;
}

// 吸附动画
function snapToEdge() {
  window.resizeTo(20, 80); // 只露出 20px
  // 鼠标靠近时滑出
}
```

### 14.1 跨平台支持

### 14.2 平台差异适配

**窗口样式：**

```
Windows 风格：
┌─────────────────────────────────────┐
│  🌟 个人助理              [—][×]   │  ← Windows 按钮
└─────────────────────────────────────┘

macOS 风格：
┌─────────────────────────────────────┐
│  ● ● ●    🌟 个人助理               │  ← macOS 红黄绿按钮
└─────────────────────────────────────┘
```

**快捷键差异：**

| 功能 | Windows | macOS |
|------|---------|-------|
| 粘贴 | Ctrl+V | ⌘+V |
| 发送 | Enter | Enter / ⌘+Enter |
| 快速便签 | Ctrl+Shift+N | ⌘+Shift+N |
| 关闭窗口 | Alt+F4 | ⌘+W |

### 14.3 国际化设计

| 元素 | 处理方式 |
|------|----------|
| 界面文字 | 使用 i18n 框架，支持中/英切换 |
| 日期时间 | 根据系统语言自动格式化 |
| 数字格式 | 千分位、小数点按地区 |
| 手写字体 | 中文：Ma Shan Zheng / 英文：Caveat |
| 棉纸纹理 | 通用，无语言差异 |

### 14.4 字体回退方案

```css
.handwriting {
  /* 中文手写 */
  font-family: 
    'Ma Shan Zheng',    /* 中文手写体 */
    'Caveat',           /* 英文手写体 */
    cursive;            /* 系统默认手写 */
}

.body-text {
  /* 正文 */
  font-family:
    '-apple-system',    /* macOS 系统字体 */
    'Noto Sans SC',     /* 中文字体 */
    'Segoe UI',         /* Windows 字体 */
    sans-serif;
}
```
