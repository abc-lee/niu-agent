## 一、设计理念

### 1.1 核心理念

**统一的关系网络** — 人和物混在一起，动态展开

- 不是树状层级，而是网状关联
- 从任意节点出发，动态构建层级
- 关系强弱通过连线粗细体现

### 1.2 两个维度

| 维度 | 说明 |
|------|------|
| **人物社会关系** | 上下级关系（如果能获取数据） |
| **动态层级展开** | 从任意节点出发，一级一级关联 |

**这两个维度融合在一起，不能分开。**

## 三、连线设计

### 3.1 连线粗细 = 关系强度

| 强度 | 粗细 | 含义 |
|------|------|------|
| 极强 | 8px | 频繁共现（5次以上） |
| 强 | 5px | 多次共现（3-5次） |
| 中等 | 3px | 少量共现（1-3次） |
| 弱 | 1px | 仅一次关联 |

### 3.2 连线样式

```css
/* 铅笔线条感 */
.relation-line {
  stroke: #999;
  stroke-width: var(--strength);
  stroke-linecap: round;
  /* 轻微不规则感 */
  filter: url(#pencil-texture);
}

/* 或简洁细线 */
.relation-line-simple {
  stroke: rgba(0, 0, 0, 0.3);
  stroke-width: var(--strength);
}
```

### 3.3 超出视口的连线

**规则：** 当前展示以外的节点，连线继续画，延伸到页面外边

```
┌─────────────────────────────────────────────┐
│                                             │
│     张三 ────── 李四                        │
│       │                                    │
│       │ ← 连线延伸到页面外                  │
│       │                                    │
│  ─────┼────────────────────────             │
│       │   表示有连接但看不到                │
│       ↓                                    │
│  (页面外：王五、赵六...)                    │
└─────────────────────────────────────────────┘
```

## 五、展示规则

### 5.1 节点数量限制

| 规则 | 说明 |
|------|------|
| **最大展示** | 2000 个节点 |
| **超出处理** | 不渲染节点，但连线继续延伸 |
| **缩放控制** | 滚轮缩放，调整可见范围 |

### 5.2 缩放交互

| 操作 | 效果 |
|------|------|
| 滚轮向上 | 放大，显示更多细节 |
| 滚轮向下 | 缩小，显示更多节点 |
| 拖拽画布 | 平移视图 |
| 双击节点 | 以该节点为中心展开 |

### 5.3 LOD（细节层次）

```
放大时：
┌───────────────────────────────────┐
│        ┌───────────┐              │
│        │    👤     │              │
│        │   张三    │              │
│        │  经理 ABC │              │
│        │ 出现: 5次 │              │
│        └───────────┘              │
│    显示完整节点信息                 │
└───────────────────────────────────┘

缩小时：
┌───────────────────────────────────┐
│     ●  ●  ●  ●  ●                │
│     ●  ●  ●  ●  ●                │
│     ●  ●  ●  ●  ●                │
│    节点简化为小点                   │
└───────────────────────────────────┘
```

## 八、视觉风格

### 8.1 延续棉纸手写风格

| 元素 | 风格 |
|------|------|
| **背景** | 米黄纸张纹理 `#faf8f0` |
| **节点** | 贴纸效果，带阴影 |
| **连线** | 铅笔线条感或简洁细线 |
| **字体** | 手写体（Ma Shan Zheng / Caveat） |
| **圆角** | 4-8px |

### 8.2 配色延续

```
便签色系（用于节点）：
├── 暖黄 #e7ca4a  ─── 文档
├── 粉红 #f8a7c8  ─── 照片
├── 嫩绿 #9bc295  ─── 组织
├── 天蓝 #78b2be  ─── 人物
├── 薄荷 #a3f0c2  ─── 便签
└── 灰绿 #c4ddc8  ─── 链接

└── 米黄 #faf8f0  ─── 页面背景
```
